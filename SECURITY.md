# Security

Please report security problems privately, not in a public issue. Two ways:

- Use **Report a vulnerability** on the Security tab of this repository (GitHub's private vulnerability reporting).
- Or use the Support tab of the Selectra listing in the Chrome Web Store.

Selectra has no server and collects no data, so the realistic problems are in the extension itself: a page that can break out of the extension's isolation, a download that reaches a private network, an input that crashes a content script. A report with a small test page that shows the problem is the most useful kind.

Only the latest release is supported.
